# СтудПоток КГУ — демонстрация

Автономная демонстрационная версия веб-интерфейса «СтудПоток КГУ» версии 13.0.1. Работает без сервера Beget.

## Запуск

Откройте `index.html` через GitHub Pages после включения публикации из ветки `main`, папка `/(root)`.

Демо-доступ: `demo / demo` (группа 13.1, 24 участника) или `demo6 / demo` (группа 13.2, 6 участников).

Вся информация в демоверсии — вымышленная. Сценарии демонстрационные, без реальной синхронизации с сервером и без настоящих аккаунтов.
